# Homebrew tap for Push Deck

[Push Deck](https://github.com/arcept/pushdeck) turns an Ableton Push 2 into a per-app controller and live display for your Mac.

```bash
brew install --cask arcept/tap/pushdeck
```

Push Deck is signed ad hoc, not with an Apple Developer ID, so the first time macOS may ask you to right-click the app in Applications, choose Open, then Open again.
Needs an Apple Silicon Mac with macOS 13 or newer.

Update with `brew upgrade --cask pushdeck`. Remove with `brew uninstall --cask pushdeck` (add `--zap` to also delete its settings).
